# SCUAD Frontend Project

This project is initialized with:
- **Node.js**: 24 LTS
- **Vite**: 7.x
- **React**: 18.3.1
- **JavaScript**

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
